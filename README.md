# AERIS-10 — Açık Kaynak Faz Dizili RADAR Sistemi

10.5 GHz frekansta çalışan, Darbe Doğrusal Frekans Modülasyonlu (PLFM) faz dizili radar sistemi. İki versiyonda mevcuttur: 3 km ve 20 km menzil. Araştırmacılar, drone geliştiriciler ve SDR meraklıları için tasarlanmış düşük maliyetli açık kaynak platform.

## Özellikler

- **Frekans:** 10.5 GHz (X-Band)
- **Modülasyon:** Darbe Doğrusal Frekans Modülasyonu (LFM)
- **Menzil:** 3 km (düşük güç) / 20 km (yüksek güç)
- **Anten:** 16 elemanlı faz dizili anten array
- **Açık Donanım:** CERN-OHL-P lisanslı
